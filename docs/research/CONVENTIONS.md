# Research conventions (all agents)

- One output file per agent, written in full before finishing, in docs/research/. Findings never live only in agent context. Write a partial file early and overwrite it as you go.
- Every number carries a source URL on the same row. Where nothing is published, estimate from a named proxy, mark the estimate with ~, label the method, and give a confidence level (high, medium, low). "Undisclosed" alone is not an answer; say which methods were tried.
- Writing standard: conclusion first; no em dashes (use commas, colons or full stops); no "X, not Y" or "rather than" contrast tics; figures as €XXM or £XXB with ~ for estimates; no arrows or word-joining slashes; bold leads end with colons.
- Tools: WebSearch and WebFetch are the first stop. `curl -sSL -A "Mozilla/5.0 ..."` from Bash works through the proxy for pages WebFetch cannot render (cinven.com, web.archive.org, find-and-update.company-information.service.gov.uk). Save any raw page you rely on under docs/research/raw/<agent>/ so it can be re-read. Run any Python that reads downloaded files with `python3 -I`.
- Do not fabricate. Do not fetch LinkedIn directly (blocked and against its terms); use Wayback Machine snapshots of public pages, press, and aggregators instead.
- Cinven context: London-headquartered European private equity firm (Cinven Partners LLP, 21 St James's Square). Funds: Eighth Cinven Fund (closed 2023, ~€13.2B), Seventh (2019, ~€10B), Sixth (2016, ~€7B), Fifth (2013, ~€5.3B), plus the Strategic Financials Fund (SFF, financial services). Six sectors: Business Services, Consumer, Financial Services, Healthcare, Industrials, Technology Media and Telecommunications. Verify every one of these figures; they are a starting point, not a source.
- Outliers: the brief is to measure the fund's typical entry and to flag anything atypical (SFF deals, minority or growth stakes, mega-deals, add-ons bought by portfolio companies, deals led from the US office) so the calibration can exclude them. Never drop an outlier silently; list it with the reason.
